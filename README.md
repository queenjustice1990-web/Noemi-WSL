# Noemi

Noemi is an early-stage project for a developer-directed platform. Its direction
is meant to come from the people building it—not from copying another product.
This repository currently contains a project landing page, not a working
platform.

## GitHub Pages

The site is published from the `main` branch by
`.github/workflows/pages.yml`. To enable deployment:

1. In the repository, open **Settings → Pages**.
2. Set **Build and deployment → Source** to **GitHub Actions**.
3. Push a change to `main`, or run the **Deploy GitHub Pages** workflow manually.

The workflow publishes the repository root as a static site. GitHub controls
Pages hosting and its applicable terms and policies. Repository visibility and
archival status are controlled by repository owners; this project cannot
technically prevent an owner from making it private or archiving it. Keep the
repository public and unarchived in **Settings → General** if public Pages
hosting is desired. GitHub Pages availability for a public repository may
depend on the account's plan and settings.
